# V Vortex Landing

Single-page portfolio landing built with React, TypeScript, Vite, Tailwind CSS, and lucide-react.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## Notes

- The layout implements the requested V Vortex creative studio structure: hero, marquee, quote, pricing, testimonial carousel, projects, partner CTA, footer, and floating bottom nav.
- `PP Neue Montreal` loads from the provided remote font URLs.
- `PP Mondwest` is referenced as `/PPMondwest-Regular.woff2`. Add that file under `public/PPMondwest-Regular.woff2` if you want the exact accent serif in the final render.
